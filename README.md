# Login Auth Frontend

Interface de autenticação desenvolvida com Angular, consumindo uma API REST de autenticação com JWT.

O projeto implementa a comunicação entre frontend e backend, permitindo registro e login de usuários com validação e tratamento de erros.

---

## Tecnologias

- Angular
- TypeScript
- HTML / CSS
- RxJS
- Angular HttpClient

---

## Funcionalidades

- Cadastro de usuário
- Login com autenticação
- Consumo de API REST
- Tratamento de erros (ex: 400 Bad Request)
- Integração com backend via HTTP
